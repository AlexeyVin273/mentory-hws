# Mentory Homeworks

Учебные задания по React и TypeScript.

- `template/` — стартовый проект; инструкция по запуску и копированию внутри.
- `module-01-lesson-01-render-counter/` — пример папки урока.

Каждый урок создаётся копированием `template` без `node_modules` и `dist`.
`AGENTS.md` переносится вместе с шаблоном: учебный код пишется вручную.
Все npm-команды выполняются внутри конкретного проекта, например `template`.

## Каталог заданий на GitHub Pages

После успешной публикации каталог доступен по адресу:
https://AlexeyVin273.github.io/mentory-hws/

Каждый урок имеет постоянную ссылку, например:

- https://AlexeyVin273.github.io/mentory-hws/module-01-lesson-01-render-counter/
- https://AlexeyVin273.github.io/mentory-hws/module-02-lesson-01-props-and-state/

Workflow `.github/workflows/deploy.yml` при push в `main` собирает все
папки вида `module-XX-lesson-YY-название` и публикует их вместе с каталогом.
Новые уроки автоматически появляются в соответствующем модуле. Папка
должна содержать `package.json` с командой `build` и `package-lock.json`.
Шаблон `template` в каталог не включается. Для публикации урок должен
находиться в `main`; задания только в других ветках не публикуются.

Сборка всего сайта из корня репозитория (Node.js 24):

```sh
node scripts/build-pages.mjs --install
```

Команда устанавливает зависимости каждого урока через `npm ci`, запускает
его обычную сборку с относительными путями к ресурсам и создаёт общий `dist/`.
Если зависимости уже установлены, можно запускать без `--install`.
Открывать результат нужно через статический HTTP-сервер с корнем `dist/`.
Учебные приложения остаются независимыми; их локальный запуск не меняется.
Если сборка любого урока завершается ошибкой, публикация не выполняется
и на GitHub Pages остаётся предыдущая успешная версия всего сайта.

## Подключение GitHub

Создай пустой публичный репозиторий `mentory-hws`, без автоматически
добавленных README, .gitignore и лицензии. Из корня этой папки выполни:

```sh
git remote add origin https://github.com/YOUR_USERNAME/mentory-hws.git
git push -u origin main
```

Замени `YOUR_USERNAME` своим логином. Если используешь GitHub CLI и он
сообщает о недействительном токене, сначала выполни `gh auth login -h github.com`.
